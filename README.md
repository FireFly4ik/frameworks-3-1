# Сервис формирования списка подарков

## Назначение

Помогает заранее выбрать подарки к праздникам и проверить, укладывается ли покупка в запланированный бюджет. На этапе ПР1 это локальный консольный прототип: за один запуск он формирует запись для одного подарка без сохранения данных.

## Целевая аудитория

Люди, которые планируют подарки для семьи, друзей или коллег и хотят контролировать расходы.

## Предметная область

Пользователь подбирает подарок конкретному человеку к определённому событию. У события есть дата, у подарка — название и цена, а у пользователя — доступный бюджет. В дальнейшем несколько подарков можно будет объединять в списки и отмечать приобретённые.

## Основные сущности

- Пользователь — владелец списков подарков и бюджета.
- Получатель — человек, которому предназначен подарок.
- Событие — повод и дата вручения подарка.
- Подарок — название, стоимость и связь с получателем и событием.
- Список подарков — набор запланированных подарков пользователя.

## Основные функции

В текущем прототипе реализованы:

1. Проверка введённых данных о получателе, событии, подарке и суммах (`validate_gift`).
2. Расчёт остатка бюджета и отказ в добавлении слишком дорогого подарка (`calculate_budget_balance`).
3. Формирование текстовой записи списка подарков (`format_gift_entry`).

## Запуск

Требуется Python 3.10 или новее. Дополнительные библиотеки не нужны.

```bash
python3 -m venv .venv
source .venv/bin/activate
python main.py
```

Введите получателя, повод, название подарка, дату в формате `ГГГГ-ММ-ДД`, цену и бюджет в целых рублях. Например, подарок за 2500 рублей при бюджете 3000 рублей даст остаток 500 рублей. Если цена выше бюджета, запись не формируется. Данные пока остаются только на экране.

## План развития

- ПР2: несколько подарков в одном списке, редактирование и сохранение в файл.
- ПР3: классы для пользователя, получателя, события и подарка.
- ПР5–ПР11: веб-приложение Django, база данных, формы и учётные записи.
- Позднее: REST API, Docker и CI/CD.

## Отладка

Для демонстрации отладки установите точку останова на строке `balance = calculate_budget_balance(price, budget)` в `main.py`. Запустите программу через отладчик IDE и введите цену `2500` и бюджет `3000`. Проверьте значения `price`, `budget` и `balance` после шага выполнения: остаток должен быть `500`. Для поиска ошибки можно временно заменить в `calculate_budget_balance` вычитание на сложение, увидеть неверное значение в отладчике и вернуть вычитание. В репозитории сохранён исправленный вариант.
