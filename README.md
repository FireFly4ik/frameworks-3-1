# Сервис формирования списка подарков

Консольное приложение для планирования подарков к событиям и контроля расходов. На этапе ПР2 сервис работает с несколькими подарками, сохраняет данные между запусками и предоставляет операции поиска, сортировки и учёта покупок.

## Возможности

- просмотр списка подарков;
- добавление подарка с получателем, поводом, датой и ценой;
- поиск по названию, получателю и поводу;
- фильтрация по максимальной цене;
- сортировка по цене или дате;
- отметка подарка купленным;
- удаление подарка;
- расчёт количества подарков, общей стоимости и остатка бюджета;
- сохранение и восстановление данных из JSON.

## Структура проекта

- `main.py` — точка запуска и циклическое меню;
- `gifts.py` — проверка и обработка коллекции подарков;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод чисел и дат;
- `data/gifts.json` — данные списка подарков;
- `tests/` — автоматизированные тесты;
- `pytest.ini` — путь импорта модулей при запуске тестов;
- `docs/` — отчёты по практическим работам.

Данные представлены списком словарей. Каждая запись содержит идентификатор, получателя, повод, название, дату, цену и признак покупки. Классы появятся на этапе ПР3.

## Требования

- Python 3.10 или новее;
- pytest;
- flake8.

Подготовка окружения:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Программа создаёт каталог `data` при первом сохранении. Если JSON повреждён, приложение сообщает об ошибке и не перезаписывает исходные данные.

## Проверка

```bash
pytest
flake8 . --exclude=.venv
```

## Развитие проекта

- ПР3: классы для пользователя, получателя, события и подарка;
- ПР5–ПР11: веб-приложение Django, база данных, формы и учётные записи;
- дальнейшие этапы: REST API, Docker и CI/CD.
