# Сервис формирования списка подарков

Консольное приложение для планирования подарков к событиям и контроля расходов. В ПР3 функциональная модель ПР2 преобразована в объектную: приложение работает с экземплярами классов, сохраняет связи между ними в JSON и восстанавливает граф объектов при запуске.

## Возможности

- просмотр и добавление подарков;
- поиск по подарку, получателю и событию;
- фильтрация по максимальной цене;
- сортировка по цене или дате;
- отметка подарка купленным и удаление;
- расчёт количества подарков, общей стоимости и остатка бюджета;
- сохранение данных между запусками;
- загрузка старого JSON-формата ПР2.

## Объектная модель

Каждая сущность находится в отдельном файле пакета `models`:

- `Recipient` (`models/recipient.py`) — получатель с идентификатором и именем;
- `Occasion` (`models/occasion.py`) — событие с датой и ссылкой на `Recipient`;
- `Gift` (`models/gift.py`) — подарок с ценой, статусом и ссылкой на `Occasion`;
- `GiftList` (`models/gift_list.py`) — именованный агрегат с собственным идентификатором, который хранит коллекцию `Gift` и выполняет поиск, фильтрацию, сортировку, удаление и расчёты.

Связи объектов:

```text
GiftList
└── Gift
    └── Occasion
        └── Recipient
```

`Gift.mark_purchased()` меняет состояние конкретного подарка. `Gift.matches()` и `Gift.is_affordable()` описывают поведение подарка. `Occasion.validate_event_date()` реализован как статический метод, а `from_data()` у сущностей — как метод класса. Свойство `Gift.status` скрывает способ формирования читаемого статуса.

## Хранение данных

Файл `data/gifts.json` содержит сведения о `gift_list` и три нормализованные коллекции: `recipients`, `occasions` и `gifts`. Связи сохраняются идентификаторами `recipient_id` и `occasion_id`. Модуль `storage.py` преобразует JSON в объекты и обратно, проверяет ссылки и сообщает об ошибках повреждённых данных.

## Установка и запуск

Требуется Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Тесты и линтеры

Конфигурация `flake8` хранится в `.flake8`, строгая проверка типов `mypy` — в `mypy.ini`, параметры тестов — в `pytest.ini`.

Полная проверка одной командой:

```bash
./scripts/check.sh
```

Отдельные команды:

```bash
python -m pytest -q
python -m flake8 .
python -m mypy .
```
